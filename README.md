# Породично стабло — упутство

Прототип сајта за породично стабло, спреман за GitHub Pages. Нема build корак —
чисти HTML/CSS/JS, довољно је да отвориш `index.html` у прегледачу да провериш
како изгледа локално, или да га поставиш на GitHub.

## Структура фајлова

```
index.html          страница
css/style.css        изглед
js/layout.js          рачуна позиције кутија и грана стабла (не мораш дирати)
js/app.js             исцртава стабло, отвара панел и галерију (не мораш дирати)
data/people.js        ОВДЕ УНОСИШ ЉУДЕ — једини фајл који треба редовно мењати
images/                ту стављаш фотографије
```

## Како додати особу

Отвори `data/people.js` и додај нови објекат у листу `PEOPLE`, по узору на
постојеће. Свака особа мора имати:

- `id` — јединствена ознака, само латиница/цртице, без размака (нпр. `"petar-jovanovic"`)
- `name` — име и презиме
- `maiden` — девојачко презиме, или `null`
- `gender` — `"m"` или `"f"`
- `birth` / `death` — година рођења / смрти (`death: null` ако је особа жива)
- `bio` — кратка биографија, неколико реченица
- `photo` — путања до главне слике (нпр. `"images/petar.jpg"`), или `null` док не додаш слику
- `gallery` — листа путања до додатних слика, нпр. `["images/petar-1.jpg", "images/petar-2.jpg"]`, или `[]`
- `parents` — листа `id` родитеља, нпр. `["nikola", "milica"]`, или `[]` ако родитељи нису у бази
- `spouse` — `id` брачног партнера, или `null`

Стабло се исцртава аутоматски на основу `parents` и `spouse` — не треба ништа
рачунати ручно, само унеси везе и распоред ће се сам направити, чак и за
неколико стотина људи.

## Како додати слике

1. Убаци фајлове слика у `images/` (нпр. `images/petar-jovanovic.jpg`).
2. У `data/people.js`, код те особе постави `photo: "images/petar-jovanovic.jpg"`.
3. За галерију, додај путање у `gallery: ["images/petar-1.jpg", "images/petar-2.jpg"]`.

Док слика није додата, приказују се иницијали имена уместо фотографије —
намерно, да се одмах види ко још нема слику.

## Постављање на GitHub Pages

1. Направи нови repo на GitHub-у и убаци у њега сав садржај овог фолдера.
2. У подешавањима repo-a иди на **Settings → Pages**.
3. Под "Source" изабери granu (нпр. `main`) и фолдер `/ (root)`.
4. Сачувај — за минут-два сајт ће бити доступан на
   `https://<korisnicko-ime>.github.io/<ime-repo-a>/`.

Свака нова измена (нови члан породице, нова слика) се само "push"-ује на
GitHub и сајт се аутоматски освежава.

## Шта прототип већ уме

- Аутоматски распоред стабла (генерације, парови, деца) — ради за 10 људи
  исто као и за 300, алгоритам је општи.
- Клик на особу отвара панел са биографијом и галеријом слика.
- Клик на слику у галерији отвара је преко целог екрана (лајтбокс).
- Zoom дугмад и превлачење мишем за навигацију кроз велико стабло.
- Прилагођено мобилним екранима.

## Шта би требало додати за 200-300 људи

- Претрага по имену (поље за унос које скролује/зумира до особе).
- Филтрирање по презимену/грани породице.
- Мини-мапа стабла у углу за оријентацију код великих стабала.

Ово су наредни кораци кад унесеш више података — прототип је направљен тако
да се лако проширује.
